# CAN_IPC_abstraction_layer

The main function of this Layer is to provide a unified data transmission interface for CAN-IPC for the multi-core heterogeneous architecture of the RDK-S100 chip.

## Getting started

CAN-IPC based on the hobot-sdk library provided by RDK-S100 has implemented a faster and more universal unified CAN data receiving and sending interface, enabling multiple programs to access data on the same physical layer CAN port.
